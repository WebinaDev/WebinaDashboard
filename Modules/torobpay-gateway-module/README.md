# TorobPay Gateway (Webina first-party)

Native WooCommerce installment BNPL gateway. Does **not** require the official TorobPay plugin.

If the official plugin is active, Dashboard settings bridge to its options and Webina skips gateway registration.

## Features
- OAuth, provision credentials, eligible, token, verify→settle, cancel, status, update
- Safe cancel-then-refund, orders admin in Dashboard, display widgets/shortcodes, campaign API
- UTM torob auto-select, DNS smart resolve, payment retry control
