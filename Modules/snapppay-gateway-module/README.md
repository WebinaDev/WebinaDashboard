# SnappPay Gateway (Webina first-party)

Native WooCommerce installment gateway. Does **not** require the official SnappPay plugin.

If the official plugin is active, the Dashboard settings UI bridges to its WooCommerce option bag and Webina does not register a duplicate gateway.

## Features
- OAuth + eligible / token / verify / settle / cancel / status / update
- Checkout eligibility gating, PDP widget, category commission
- Dashboard settings, test-connection, transaction logs
