# Definition of Done — هر صفحهٔ داشبورد

هر مسیر README باید قبل از «انجام» این معیارها را داشته باشد:

1. **داده**: بارگذاری از REST با خطای قابل‌نمایش (toast) و حالت loading (skeleton).
2. **خالی**: empty state با راهنمای عمل بعدی (مثلاً «اول محصول بسازید»).
3. **CRUD**: حداقل عملیات لازم README (لیست، ایجاد، ویرایش، حذف در صورت مجاز نقش).
4. **دسترسی**: مخفی یا 403 وقتی capability کاربر کافی نیست.
5. **i18n**: همهٔ رشته‌های UI در `en`/`fa`؛ تاریخ و عدد با قواعد زبان.
6. **ریسپانسیو**: جدول scroll افقی یا card-stack در موبایل؛ ناوبری قابل استفاده با `Sheet` در sidebar.
7. **بدون placeholder**: هیچ متن «به زودی» یا کامپوننت `ModulePlaceholder` در آن مسیر.

صفحات: پیشخوان، پست‌ها، پست جدید/ویرایش، دستهٔ نوشته، رسانه، برگه‌ها، محصولات، محصول جدید/ویرایش، برندها، دسته محصول، ویژگی‌ها، سفارشات، جزئی سفارش، گزارش فروش، کوپن، کاربران، کاربر جدید، دیدگاه‌ها، آمار، تنظیمات.
