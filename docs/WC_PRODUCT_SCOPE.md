# دامنهٔ محصول ووکامرس در داشبورد (هم‌راست با README ۵.۱ و ۵.۲)

## README — خلاصهٔ الزام

| بند | متن README | تفسیر فنی |
|-----|------------|-----------|
| ۵.۱ | لیست محصولات کامل، سینک با Webina-Woo-Core، قیمت‌های مختلف | لیست + ستون‌های قیمت (عادی/حراج در صورت وجود در API)، فیلدهای افزونهٔ WFCP در صورت فعال بودن |

## فاز فعلی در کد (Phase A — «هستهٔ ساده»)

منبع داده: REST داخلی پلاگین (`shop/products`, `PATCH` محصول).

| حوزه | پوشش فعلی | خارج از فاز فعلی |
|------|------------|-------------------|
| نوع محصول | عملاً `simple` (ایجاد پیش‌فرض ساده) | grouped, external, variable |
| قیمت | `regular`, `sale` | قیمت tiered، قوانین پویا WC، قیمت متغیر per variation |
| موجودی | `manage_stock`, `stock_quantity` | backorders، مدیریت per variation |
| محتوا | `short_description`, `description` (HTML) | ویرایشگر بلوکی مطابق admin |
| شناسه | `sku`, `status` | GTIN/global attributes در UI |
| WFCP | `purchase_price`, `lock_price`, … در صورت `flags.wfcp` | هر فیلد اضافی افزونه بدون قرارداد جدا |
| گالری / تصویر شاخص | REST ممکن است داشته باشد؛ UI ویرایشگر **کامل گالری** در این فاز نیست | چندتصویر، مرتب‌سازی drag |
| دسته محصول / برند / ویژگی در فرم محصول | صفحات جداگانه taxonomy | انتخاب چندگانه در همان فرم محصول |
| متغیرها | — | تب variations، قیمت per variation |

## فاز هدف README (Phase B — «نزدیک ووکامرس admin»)

برای رسیدن به README ۵.۲ به‌صورت جدی، باید به‌ترتیب اولویت:

1. **تصویر شاخص + گالری** از REST و UI (آپلود رسانه، ترتیب).
2. **دسته‌های محصول و برند** روی همان فرم (multi-select).
3. **ویژگی‌ها** (attributes) و اتصال به محصول.
4. **نوع variable** + جدول variations (حداقل قیمت و SKU و موجودی).
5. **وزن/ابعاد/حمل** در صورت نیاز کسب‌وکار.
6. **هم‌ترازی فیلدهای WFCP** طبق [WOO_CORE_SYNC.md](./WOO_CORE_SYNC.md).

تا وقتی Phase B تمام نشود، README ۵.۲ را باید «هدف بلندمدت» دانست، نه وضعیت فعلی کد.

## قرارداد API (خلاصه)

فیلدهای قابل‌اعتماد برای Phase A در پاسخ/درخواست PATCH باید با `includes/class-webino-dashboard-rest*.php` هم‌خوان باشند؛ هر فیلد جدید UI باید هم‌زمان در REST map شود.

برای جزئیات یکپارچگی با افزونهٔ فروش، سند **WOO_CORE_SYNC** را ببینید.
